##  Project Overview

In this project, I worked on managing appointment data for a healthcare scenario where patients schedule appointments with doctors.
The core objective was to ensure smooth data handling and enable easy updates, retrieval, and reporting.

---

##  Technologies Used

- MySQL
- SQL Queries (CRUD Operations)
- Stored Procedures

---

##  Key Steps Performed

1. **Viewed All Patient Appointments**  
   - Retrieved and reviewed the entire appointment data.

2. **Filtered Appointments by Patient ID**  
   - Extracted specific appointment records for individual patients.

3. **Scheduled New Appointments**  
   - Inserted new appointment entries into the database.

4. **Verified Inserted Records**  
   - Cross-checked newly added appointments to ensure data integrity.

5. **Updated Appointment Status**  
   - Marked appointments as Completed after they were attended.

6. **Cancelled Appointments**  
   - Updated appointment records to reflect cancellations.

7. **Generated Daily Appointment Reports**  
   - Created summaries to display the total number of appointments for each doctor on a specific day.

8. **Automated Appointment Scheduling Using Stored Procedures**  
   - Used stored procedures to efficiently handle appointment insertions and reduce manual effort.

9. **Validated Automation Results**  
   - Verified that the stored procedures correctly inserted new appointments.
